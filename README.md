# Future Letters ✉️

**Write today. Revisit tomorrow. Share a little piece of your heart.**

Future Letters is a web application where you can write letters to your future self or create heartfelt letters for friends. Turn your thoughts, hopes, and memories into something meaningful, then share a letter through a link or pair it with a gift for someone special.

🔗 **Live Demo:** [futureletters.vercel.app](https://futureletters.vercel.app/)

## ✨ Features

- **User Authentication** — Create an account and access your personal letter-writing experience.
- **Letters to Your Future Self** — Write letters to revisit at another point in your life.
- **Letters for Friends** — Create personal messages for the people who matter to you.
- **Shareable Links** — Share letters with friends through a link.
- **Digital Gifts** — Add a thoughtful gift to make a letter more special.
- **Personal Letter Experience** — Keep your words and memories in one place.

## 🛠️ Tech Stack

- **Frontend:** React, Vite
- **Styling:** Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Deployment:** Vercel (frontend)

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- MongoDB

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/MuzdalfaZulfiqar/paper-star-jar.git
cd paper-star-jar
```

**2. Install frontend dependencies**

```bash
cd client
npm install
npm run dev
```

**3. Install backend dependencies**

In a separate terminal:

```bash
cd server
npm install
```

Create a `.env` file in the `server` directory and configure the environment variables required by your application. Check the server configuration for the exact variable names.

Start the backend using the start script defined in `server/package.json`.

## 💌 The Idea Behind Future Letters

Some words are worth saving for another day. Some feelings are easier to express when we take the time to write them down.

Future Letters is built around the idea that a letter can be more than a message. It can be a reminder of who we were, a gift for someone we love, or a little surprise waiting to be discovered.
